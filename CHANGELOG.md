# Changelog

Versions are generated by [Changesets](.changeset/README.md). The five library packages plus
`@conduit/db` share one version number; `@conduit/cli` and `@conduit/bridge` are private applications
and are not versioned for release.

## 0.1.0 — 2026-09-28

First numbered version. Nothing is published; this replaces `0.0.0` so that the next change has
something to increment.

### What exists

- **`@conduit/core`** — the Common Data Model, the provider interface, a closed error taxonomy, and a
  one-function logger. Timestamps are `bigint` nanoseconds everywhere and money is integer
  micro-units.
- **`@conduit/providers`** — Polygon, Alpaca, Databento and Tiingo. Databento and Tiingo are
  replay-only; an adapter that cannot serve a shape throws `CoverageError` rather than quietly
  returning a different one.
- **`@conduit/symbology`** — FIGI resolution with a temporal security master, so a query with a past
  `asOf` is answered from local data rather than from OpenFIGI's view of today.
- **`@conduit/ledger`** — REST, subscription and message accounting per provider per window, refusing
  locally before a provider answers 429.
- **`@conduit/client`** — the failover router: coverage, then health, then per-symbol out-of-order
  suppression, with control messages on the consumer's own stream.
- **`@conduit/cli`** — `conduit doctor`, `spend`, `resolve`, `stream`.
- **`@conduit/bridge`** — Conduit as a subprocess speaking newline-delimited JSON, for consumers that
  are not TypeScript.

### Fixed before 0.1.0

The bugs worth knowing about, because each one was wrong in a way the test suite could not see.

- **Alpaca's stream authenticated before the server's hello**, so the frame was ignored and the
  socket stayed open and silent until the server's own auth timeout. Polygon had the same ordering.
- **Socket backoff reset on every connection.** A socket rejected at the application level completes
  its handshake, so every retry looked like the first and the delay never grew.
- **An unproductive socket retried forever in silence.** A stream that could never deliver produced no
  data, no error and no control message. There are now three bounds on it: a retry budget that
  reports the underlying error, a timeout on an open socket that never authenticates, and immediate
  termination on a pre-auth rejection.
- **`@conduit/ledger` and `@conduit/symbology` were uninstallable** — both emit a type import from
  `@conduit/db`, which had been excluded from the published set.
- **`@conduit/providers` leaked `ws` and `Buffer` into its public types** without declaring the type
  packages, breaking any consumer compiling with `skipLibCheck: false`.
- **Polygon quote sizes were 100× too large** — the vendor moved from lots to shares on 2025-11-03.
- **Alpaca's websocket error 410 was mapped to `AuthError`**, which reported a working key as revoked
  and dropped it from coverage. It is a coverage gap.
- **Polygon accepted a replay window and silently returned live data.**
- **Venue and condition-code tables were hand-written and wrong**, under a comment claiming they had
  been verified. Both now ship empty and are loaded from the vendor's own endpoint with your key.
- **Staleness detection thrashed between providers overnight.** It now requires corroboration from a
  standby's snapshot, which needs no market calendar.

### Verification

Three checks, because each one sees something the others cannot:

| Command | Catches |
|---|---|
| `pnpm test` | logic errors, against fixtures written from vendor documentation |
| `pnpm live` | protocol errors, against a real Alpaca server sending invented ticks |
| `pnpm truth` | wrong numbers, against an independent vendor |
| `pnpm smoke` | packaging errors, by installing into an empty project |

`pnpm truth` found no scaling, shifting or field-mapping error across five symbols. It did establish
that `prevClose` on Alpaca's free IEX plan sits 0–5 cents from the official close, because one venue's
daily bar cannot contain the closing auction. That is structural, it is documented, and it changes what
a UI shows as the day's change.

### Known limitation

No real tick has ever arrived over a stream. The handshake runs against Alpaca for real, but the
account's single free-plan data connection is held elsewhere, so every attempt is refused with 406.
Details in [docs/conformance.md](docs/conformance.md#what-running-it-found).

### Guard

Alpaca's sandbox lives at `/v2/test`, one path segment from `/v2/iex`, and quotes a symbol called
FAKEPACA at prices nobody traded at. The feed name was read from the environment through an unchecked
`as 'iex' | 'sip'` cast, so `ALPACA_FEED=test` built the sandbox URL and would have served invented
prices to a consumer with nothing saying so. Now: the feed name is validated, the adapter refuses a
sandbox URL without `allowSyntheticData: true`, `ProviderAdapter.synthetic` puts the disclosure on the
interface, and the bridge refuses to start against a synthetic feed unless `CONDUIT_ALLOW_SYNTHETIC=1`.
